# MiFreeformUnbounded v3.1.1-rc.1

2026-10-31 · 预发布 / Prerelease · versionCode `20261096`

## 中文

- 静态作用域补齐月球、雪山、几何、土星、地球和火星六个超级壁纸包，与系统界面、息屏与锁屏编辑及 MiWallpaper 共九项。
- 模块状态使用同一份作用域名单识别主进程和子进程，避免把名称相似的无关应用算作已激活目标。
- APK 的 Android 与 Xposed 版本由同一个版本源生成，并在打包后校验。

### 已知问题

- AOD 转入锁屏时，前景轮廓与时钟遮罩仍可能短暂不同步。
- 整机冷启动及首次解锁前的景深恢复尚未完成真机验收。
- 景深主要在雪山壁纸上验证。声明其他超级壁纸作用域不代表这些壁纸已完成适配验收。

### 安装

下载 `MiFreeformUnbounded-v3.1.1-rc.1.apk`，可用 `SHA256SUMS.txt` 校验。与 v3.1.0、v3.0.2-beta.2 及 CI.94 同签名的版本可覆盖升级。公开 v3.0.0 和部分 Debug 测试包签名不同，不能直接覆盖安装。

安装后在 LSPosed 中确认模块已启用，再按需重启相关作用域。本版为测试版本，正式版用户可继续使用 v3.1.0。

## English

- Adds the six missing Super-wallpaper packages: Moon, Snowmountain, Geometry, Saturn, Earth and Mars. Together with System UI, the AOD/lock-screen editor and MiWallpaper, the static scope contains nine targets.
- Module status uses the same scope list for main and child processes, without counting unrelated apps with similar names.
- Android and Xposed version metadata are generated from one source and checked in the packaged APK.

### Known issues

- Brief foreground/clock-mask misalignment can still occur during AOD-to-lock-screen transitions.
- Full cold-boot and pre-unlock depth recovery have not completed device acceptance.
- Depth testing has focused on Snowmountain. Declaring the other Super-wallpaper scopes does not establish compatibility with every wallpaper.

### Installation

Download `MiFreeformUnbounded-v3.1.1-rc.1.apk` and verify it with `SHA256SUMS.txt`. Builds signed like v3.1.0, v3.0.2-beta.2 and CI.94 support in-place upgrades. Public v3.0.0 and some Debug builds use a different certificate and cannot be upgraded directly.

After installation, check that the module is enabled in LSPosed and restart the relevant scopes. This is a test release; stable users can remain on v3.1.0.
