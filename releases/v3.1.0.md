# MiFreeformUnbounded v3.1.0

2026-10-30 · 正式版 / Stable · versionCode `20261095`

## 中文

本版汇总 3.0.2 预发布阶段的功能与修复。由于包含新增功能，按语义化版本发布为 3.1.0。

- 首页仅保留当前超级壁纸，其余收进“更多”；统一首页、配置、设置入口，全部外观选项位于二级页。
- 重启弹窗隐藏底栏，更新重启图标和组合勾选；逐项检查九个作用域及子进程，区分未运行项与失败项，最后重启 SystemUI。
- 完善关于页名称和镂空图标流光、渐变顶栏、模块说明排版及功能图标；边缘安全距离可调上限增至 2000px。
- 超级壁纸景深使用已校验渲染入口的原始深度生成全分辨率时钟遮罩；修复相关进程重建后采集恢复，以及 SystemUI 晚启动时静止末帧丢失的问题。
- 同一窗口内的时钟统一采用一次绘制的遮罩快照，避免多个时钟目标在一次绘制中各自采用不同帧。

### 验证与已知问题

- 景深代码已通过 118 项 Android 单元测试、Debug/Release Lint、Release 构建与 native 库一致性检查。Instrumentation 仅编译，未执行。
- 已安装 CI.94 验证：接收端延迟 45 秒后，静止雪山自动恢复景深，未重启壁纸进程；Provider 和雪山单独重建回归通过。
- **AOD→锁屏仍可能出现极短的轮廓/遮罩不同步；原始录像尚未完成全帧视觉验收，不宣称此问题已解决。** 壁纸/遮罩事务配对实验默认关闭。
- **真实整机冷启动及首次解锁前的恢复尚未完成实机验收。** 45 秒晚启动模拟不能替代冷启动验收。
- 顶部渐变已更新实现和截图检查，用户最终视觉确认仍待完成。
- 精确 native 渲染适配限于已校验的设备库；其他 HyperOS 构建可能跳过不匹配入口。不能把静态作用域包含六个超级壁纸理解为六种均完成景深真机适配验收。

### 安装与升级

下载 `MiFreeformUnbounded-v3.1.0.apk`；`SHA256SUMS.txt` 可用于校验文件。本版延续公开 beta.2 与 CI.94 的签名，可从该渠道覆盖升级。**公开 v3.0.0 的签名不同，不能直接覆盖升级**；独立 Debug 测试渠道也可能使用另一签名。请先确认已安装渠道并保留配置，不要为了升级盲目卸载或清除数据。

安装后在模块管理器中启用，再按需重启对应作用域。修改功能配置后也需重启对应进程。

## English

This release consolidates the features and fixes developed during the 3.0.2 prereleases. The added functionality warrants version 3.1.0 under Semantic Versioning.

- Home shows the active Super wallpaper and moves the others into More. Home, Configuration, and Settings are distinct pages, with all appearance options on a secondary page.
- The restart dialog hides navigation and uses revised restart and selection icons. Restart checks cover nine scopes and their child processes, distinguish inactive targets from failures, and handle SystemUI last.
- Refines About shimmer, the hollow logo, gradient header, module information, and semantic icons. The configurable edge-distance limit increases to 2000px.
- Uses verified renderer depth to generate a full-resolution clock mask. Restores capture after relevant process recreation and replays a stationary final mask when SystemUI starts late.
- Clock targets in the same window adopt one mask snapshot per draw.

### Validation and known issues

- The depth implementation passed 118 Android unit tests, Debug/Release lint, the Release build, and packaged native-library checks. Instrumentation was compiled but not run.
- Installed CI.94 recovered stationary Snowmountain depth after an intentional 45-second receiver delay without restarting the wallpaper process. Provider-only and wallpaper-only restarts also passed.
- **Occasional brief contour/mask misalignment during AOD→lockscreen remains unresolved. Full original-frame visual acceptance is incomplete.** Wallpaper/mask transaction pairing remains disabled by default.
- **Actual full cold-boot and pre-unlock recovery have not completed device acceptance.** The delayed-start simulation is not a substitute for those checks.
- The gradient header implementation and screenshots were checked; final user visual confirmation remains pending.
- Native renderer support is limited to verified device libraries. Incompatible HyperOS builds skip unmatched entry points. Declaring all six Super-wallpaper scopes does not imply device acceptance of all six wallpapers.

### Installation and upgrades

Download `MiFreeformUnbounded-v3.1.0.apk` and verify it with `SHA256SUMS.txt`. It retains the public beta.2 and CI.94 certificate for in-place upgrades from that channel. **The public v3.0.0 certificate is different and cannot be upgraded in place.** Dedicated Debug builds can also use another certificate. Check the installed channel and preserve configuration; do not blindly uninstall or clear data to switch channels.

Enable the module in a compatible manager and restart the relevant scopes. Configuration changes also require the corresponding process to restart.
